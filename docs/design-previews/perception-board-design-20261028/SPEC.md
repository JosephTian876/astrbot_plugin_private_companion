# 感知功能板设计

预览：preview.png / index.html

## 结构

- 保留原版多个功能板组合：时空与环境、现实感知、对话与模型、外部与记录。
- 功能板内每个条目都是独立点击目标。
- 点击某个条目后，在功能板下方打开单项配置抽屉。
- 不展开整个分类配置，不跳转到整类设置页。

## 功能板条目

每个条目统一显示：图标、名称、当前值或状态、来源或时效、状态徽标。点击后在下方打开该条目的配置。

## 单项配置抽屉

- 标题格式：功能板 / 条目，例如 现实感知 / 华为运动健康。
- 只展示当前条目相关字段、开关和保存按钮。
- 同时只打开一个抽屉；点击其他条目时替换内容。
- 复杂配置可保留打开完整设置入口，但默认不展开整个分类。

## 视觉

沿用原版绿色和米白配色、圆角描边卡片、轻阴影和紧凑行高。不使用时间线、三栏看板或独立分类页签。
