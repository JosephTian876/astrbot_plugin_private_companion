# 本轮感知 · 三版设计稿

共同内容模型：展示当前私聊角色最近一轮回复实际进入模型上下文的材料。

## 三版

- v1-command-list.png：清单版。左侧实际注入清单，右侧本轮概览与待处理。
- v2-narrative-flow.png：叙事版。沿时间线展示角色本轮真正知道了什么。
- v3-three-lanes.png：三栏版。实际注入 / 可用未使用 / 需要处理三栏并列。

## 只展示

- 本轮实际注入：时间、日历、天气地点、互动间隔、熟人卡、记忆、未完成事项、已发送消息等。
- 可用但未使用：识屏、摄像头、手机状态、外部资讯、余额感知等。
- 需要处理：健康未绑定、手机未授权等会阻止感知的项目。
- 页头：私聊对象、角色、最近一轮时间、模型、注入数量、工具调用次数。

## 不展示

- TTS、生图、视觉等模型配置磁贴。
- 新闻列表、余额设置、撤回记录详情。
- 任何配置表单。
- 刷新导致的新采集。
