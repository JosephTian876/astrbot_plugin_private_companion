# 感知仪表盘 · 呼吸感改版

预览：`preview.png` / `index.html`

## 与第一版的区别

- 去掉一排排等宽卡片，改为「一条环境带 + 三条纵向叙事线」。
- 主视觉只保留一个「此刻」大面板：时间、天气、地点和待处理动作在同一空间里。
- 健康不再是一张横向摘要卡，而是一条独立的「身体 / 健康」叙事线，绑定、状态和边界说明沿同一列展开。
- 模型能力降为右侧紧凑的「连接」状态，不再用四个大磁贴占据主视觉。
- 「今天」用时间线呈现最近发生、主动联系窗口和外部资讯，而不是静态状态卡。
- 卡片边界减少，用留白、细分隔线和淡背景块组织层级。

## 布局

1. 顶部：标题、同步时间、通道计数、重新读取。
2. 环境带：时钟 / 日期 / 天气 / 预警 / 待处理动作。
3. 三列内容：
   - 左：身体与健康（绑定、数据范围、使用边界、入口）。
   - 中：今天（刷新、天气、主动联系窗口、外部资讯、撤回记录）。
   - 右：连接（现实触及、模型路由、外部与记录、健康感知的紧凑状态）+ 健康边界提示。

## 设计意图

- 仪表盘应该像「此刻的桌面」，而不是「配置卡片的堆叠」。
- 让用户先感知环境与状态，再决定是否进入配置。
- 健康保留独立叙事，不被模型、设备或外部资讯吞掉。
- 颜色更克制：绿色表示可用，琥珀色表示待授权/待处理，灰色表示未配置。
